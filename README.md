# AutoMote offline charts

OpenStreetMap-derived geographic overview packages, licensed under ODbL 1.0.

Copyright OpenStreetMap contributors. https://www.openstreetmap.org/copyright
Licence: https://opendatacommons.org/licenses/odbl/1-0/

The .amchart release asset contains the derived chart database, selected original source geometry, manifest, SHA256 checksums and licence/provenance notice. It is UTF-8 JSON; no special extraction software or account is required. This repository contains no private AutoMote application code.

Cannes-Sanremo: extracts downloaded 2026-10-29 from Geofabrik (Provence-Alpes-Cote-d-Azur, Nord-Ovest Italy, Monaco). Coverage: 6.85-7.95 E, 43.25-43.95 N. Geographic overview only: no depths, hazards, navigation routes or verified harbor approaches.

Sources: https://download.geofabrik.de/europe/france/provence-alpes-cote-d-azur.html https://download.geofabrik.de/europe/italy/nord-ovest.html https://download.geofabrik.de/europe/monaco.html
